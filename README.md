# 🎲 Dice Infinity - サイコロクリッカーゲーム

ブラウザで遊べる放置系クリッカーゲームです。サイコロを振ってポイントを稼ぎ、アップグレードでインフレしていく中毒性の高いゲームです。

## 🎮 遊び方

### 起動方法

1. **ローカルサーバーで起動（推奨）**
   ```bash
   # Python3の場合
   python3 -m http.server 8000

   # Python2の場合
   python -m SimpleHTTPServer 8000
   ```

2. **ブラウザでアクセス**
   ```
   http://localhost:8000
   ```

3. **直接開く（一部機能が制限される可能性あり）**
   - index.htmlをダブルクリックでブラウザで開く

### 基本操作

1. **サイコロをクリック**: メイン画面の大きなサイコロをクリック/タップして振る
2. **アップグレード購入**: 貯めたポイントでアップグレードを購入
3. **タブ切り替え**: Basic, Evolution, Multiplier, Special, Prestigeタブを切り替えて様々なアップグレードにアクセス
4. **セーブ**: 自動セーブ（30秒ごと）または手動セーブボタン
5. **プレステージ**: 100万ポイント到達後、リセットして永続的なボーナスを獲得

## 📊 ゲームシステム

### アップグレードの種類

#### 基礎 (Basic)
- **Auto Roller**: 自動でサイコロを振る
- **Dice Master**: サイコロの出目にボーナス
- **Lucky Hand**: クリティカル率アップ

#### 進化 (Evolution)
- **D8**: 8面サイコロに進化
- **D10**: 10面サイコロに進化
- **D12**: 12面サイコロに進化
- **D20**: 20面サイコロに進化
- **D100**: 100面サイコロに進化

#### マルチプライヤー (Multiplier)
- **Double Roll**: 複数個のサイコロを同時に振る
- **Triple Roll**: さらに多くのサイコロを振る
- **Mega Roll**: 全体的な倍率アップ
- **Ultra Roll**: 超強力な倍率

#### 特殊効果 (Special)
- **Lucky 7**: 7が出ると7倍
- **Golden Dice**: 1%の確率で100倍
- **Combo System**: 連続ボーナス
- **Fever Mode**: 短時間の超倍率

#### プレステージ (Prestige)
- **Blessing of Beginning**: 永続的なポイントボーナス
- **Divine Protection**: クリティカルとクリック強化
- **Flow of Time**: DPS強化
- **Infinite Possibility**: 全体的な獲得量アップ

## 🎯 ゲーム目標

1. **初級**: 初めての8面サイコロ獲得（1,000ポイント累計）
2. **中級**: 20面サイコロ獲得（1,000,000ポイント累計）
3. **上級**: 初めてのプレステージ（1,000,000ポイント到達）
4. **エンドゲーム**: 全アップグレード解放、天命ポイント100

## 💾 データ管理

- **自動セーブ**: 30秒ごとに自動でLocalStorageに保存
- **手動セーブ**: ヘッダーの「Save」ボタンで手動保存
- **リセット**: 「Reset」ボタンで全データを削除（要確認）
- **プレステージ**: 通常アップグレードをリセットし、天命ポイントを獲得
